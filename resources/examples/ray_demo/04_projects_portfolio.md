# 1. NEAT — Neutron Bragg Edge Analysis Toolkit

## Type

Scientific software / data analysis / workflow automation

## Problem

Bragg-edge imaging analysis involves preprocessing, normalisation, fitting, spatial aggregation, mapping, and interpretation. Manual workflows can be slow and difficult for non-specialist users.

## Contribution

- Developed a reusable analysis toolkit rather than a one-off script.
- Implemented preprocessing and normalisation workflows.
- Implemented Bragg-edge fitting capability.
- Supported pseudo-Voigt-step fitting approaches.
- Supported multi-stage fitting.
- Added batch-processing capability.
- Added macro-pixel analysis.
- Added mapping workflows.
- Worked with uncertainty / signal-quality considerations.
- Supported RADEN-related analysis requirements.

## Impact

A representative workflow was reduced from approximately 2 hours to approximately 20 minutes.

## Skills

- Python
- Data analysis
- Scientific software
- Optimisation / fitting
- Workflow automation
- GUI / UX thinking
- Productisation of scientific workflows
- Domain-specific software
