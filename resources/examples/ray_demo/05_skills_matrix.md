# Skill Claim Rules

Career Agent must use these categories carefully.

### Demonstrated
Direct project/work evidence exists.

### Strong transferable
Adjacent experience provides strong evidence, but the exact context differs.

### Developing
The candidate is actively learning/building but does not yet have substantial professional evidence.

### Awareness
Concept is understood but hands-on evidence is weak.

Never upgrade a skill level for the purpose of improving a CV match.
